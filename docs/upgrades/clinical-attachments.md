# Clinical attachment handling

New or changed clinical attachments must be JPEG, PNG or PDF files no larger
than 10 MB. Rejected uploads leave the case open so the user can remove or
replace the file and save again.

Existing files can remain attached when an unrelated case field changes,
including files accepted under an older format or size policy. Retention
requires the same attachment identifier, type and bytes within the current case.
Unsupported historical files cannot be previewed; replace them with a supported
file when a preview is needed.
