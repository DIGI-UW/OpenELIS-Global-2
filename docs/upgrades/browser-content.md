# Branding and Help links

Uploaded logos support PNG and JPEG. SVG upload and serving support has been
removed; stored SVG logos are retained on disk but return 404. Replace any
custom SVG logo with a PNG or JPEG. Existing raster favicon files remain
supported. No database migration or automatic file deletion is required.

Configured Help links support HTTP, HTTPS and relative web paths. Unsupported or
malformed URLs disable the affected Help action. Links open in a separate window
without access to the originating window.
