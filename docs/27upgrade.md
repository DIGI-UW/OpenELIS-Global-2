# Historical 2.7 upgrade

This procedure depended on the retired Python installer and is not a current
installation or upgrade path. The
[historical procedure](https://github.com/DIGI-UW/OpenELIS-Global-2/blob/13337b74c3/docs/27upgrade.md)
remains available in Git history for sites planning a migration from those
versions. Test that migration against a copy of the existing database and retain
its configuration and encryption keys.

For current installations, use the [installation guide](install.md) and
[upgrade guide](upgrade.md). The online and offline distributions use the same
released images and configuration.
