### Inversion Proof

The core selection guard was deliberately inverted locally by removing
`run.isReportable()` from `isReportableReviewed`. The focused test failed because
`run-not-reportable` entered `astReadingDAO.getByRunIds` alongside
`run-selected`. Restoring the condition returned the same test to green. The
intentional failing edit was never committed.
