# Historical Feature 012: Generic ASTM Profiles

**Status:** Superseded as an OGC-1054 engineering specification

Feature 012 records an earlier profile/API design. Its former plan, schema,
tasks, and validation material are not executable because OGC-1054 evolves the
established profile system into one Bridge-owned immutable catalog. Git history
preserves the removed material.

Current work is governed by the
[OGC-1054 specification](../OGC-1054-analyzer-qc-config/spec.md),
[authoritative roadmap](../roadmaps/ogc-1054-analyzer-feature-roadmap.md), and
[`AGENTS.md`](../../AGENTS.md). A profile has exactly two jobs: define runtime
communication for one analyzer type and supply defaults for a new Bridge
connection.
