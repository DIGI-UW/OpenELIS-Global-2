# OGC-1054 MVP Acceptance Matrix

This matrix elaborates the roadmap's normative `MVP-001` through `MVP-024`
criteria. It does not track progress. A criterion is finished only as part of
the roadmap iteration that owns it.

## Cross-Checkpoint Profile Compatibility Gate

F0, BR-E0, OE-E0, BR-M1, and OE-M1 cannot close unless the established
GeneXpert ASTM and FluoroCycler profiles retain both required jobs:
communication/runtime definition and defaults for a new OpenELIS analyzer
instance. Required proof is the unabridged profile fixture under the accepted
schema, producer/consumer contract tests, OE default-application tests, Bridge
runtime/mock transport tests, and assembled parity. A metadata-only catalog,
translated thin fixture, hardcoded frontend default, or old video cannot pass
this gate.

## G0 Final Acceptance Package

Only G0 creates a standalone package. It contains generated target metadata,
the downloaded Grist Markdown/JSON report, non-video test result, inspected
screenshots, trace, console review, and MP4. Changing the application or
checklist invalidates the package and restarts the G0 acceptance run.
