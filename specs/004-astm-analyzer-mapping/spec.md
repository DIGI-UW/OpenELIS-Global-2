# Historical Feature 004: ASTM Analyzer Mapping

**Status:** Superseded as an OGC-1054 engineering specification

Feature 004 records early ASTM mapping, raw-import, plugin-registry, and user
interface work. Its former plan, data model, API, tasks, research, and mock
screen specifications conflict with the Bridge-owned target in several places
and have been removed from the active tree. Git history preserves them.

Current work is governed by the
[OGC-1054 specification](../OGC-1054-analyzer-qc-config/spec.md),
[authoritative roadmap](../roadmaps/ogc-1054-analyzer-feature-roadmap.md), and
[`AGENTS.md`](../../AGENTS.md). Bridge owns ASTM listeners and parsing;
OpenELIS owns local catalog binding, held results, review, and operational QC.

Current functional and visual intent comes from
[`openelis-work@main`](https://github.com/DIGI-UW/openelis-work/tree/main/designs/analyzer-integration)
only as product input.
